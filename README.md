# SMART CITY 2030 — Digital Command Operating System

> **Building a Connected, Intelligent & Sustainable Future**

Smart City 2030 is an ultra-modern, cinematic, futuristic web application designed as a real-time digital command center for intelligent urban infrastructure. Powered by Artificial Intelligence, Internet of Things, Digital Twins, Clean Energy Grid, and Zero-Trust Cybersecurity.

---

## 🌟 Key Features

- **Cinematic Video & Poster Background**: Background video integration with automated poster fallback (`public/images/smart-city-poster.jpg`) and dark gradient shader canvas overlay.
- **Real-Time Command Dashboard**: Live telemetry monitoring traffic flow, energy grid health, air quality, water networks, public safety, and smart waste management.
- **AI City Brain**: Interactive 5-step decision pipeline (`DATA` → `ANALYSIS` → `PREDICTION` → `DECISION` → `ACTION`) with live prediction cards and automated dispatch triggers.
- **Digital Twin Spatial Mirror**: Interactive 2D/3D isometric city simulation viewer with live layer controls (`LIVE`, `TRAFFIC`, `ENERGY`, `AIR QUALITY`, `WATER`, `EMERGENCY`).
- **Interactive City Map**: Clickable GIS pins for Smart Hospitals, Central Transit Nodes, Solar Hubs, Reservoirs, Parks, EV Chargers, and Emergency Stations with full status modals.
- **Smart Mobility & Traffic Forecast**: Level 5 autonomous transit stats + SVG/CSS hourly traffic prediction chart with AI alternate route recommendations.
- **Clean Energy & Sustainability**: 2.8 GW solar/wind share breakdown, battery reserve storage, and power routing flowchart.
- **Smart Water & Waste Management**: Hydrostatic leak telemetry + smart waste bin fill sensors (#204, #205, #206) with AI collection route recommendation.
- **Smart Buildings & Autonomous Fleet**: Zero-carbon building metrics (Energy, Water, Occupancy, CO2) + 42 Drones, 128 AVs, 36 Robots fleet tracking.
- **Public Safety & Healthcare**: 96% security score, 4.2 min emergency response, interactive Emergency SOS dispatch simulation modal, and healthcare capacity telemetry.
- **Smart Agriculture & Cybersecurity**: Precision soil sensors + Quantum Threat Hunting terminal log inspecting network traffic 24/7.
- **Citizen Digital Portal**: Interactive service cards with issue reporting form modal.
- **ARIA AI Assistant**: Floating bottom-right AI chatbot widget with quick prompt pills and instant answers.
- **13 Tech Architecture Cards**: Deep spec modals for AI/ML, IoT, Digital Twins, Edge Computing, 5G/6G, AR/VR, and more.
- **2030 Strategic Roadmap**: Animated 2026-2030 milestone timeline.

## 🎨 Design System & Typography

- **Primary Typography**: `Times New Roman, Times, serif` (Headings, Paragraphs, Cards, Buttons, Nav, Modals, Forms, Footer).
- **Secondary HUD Typography**: `Space Grotesk` (HUD Badges, Digital Metrics, Status Badges, System Indicators, Tech Tags).
- **Styling**: Glassmorphism, neon glow accents (`#00f3ff`, `#00ff9d`, `#bf00ff`, `#ff3366`), dark cinematic overlay, scanlines, and responsive layout grid.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v16+) installed.

### Installation

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

Open your browser at `http://localhost:3000`.

### Build for Production

```bash
npm run build
```

The production output will be generated in the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```
